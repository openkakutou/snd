## Modules

## Observed patterns
- Read path is split into a cheap parse step (`ParseV1`, locates each sound's offset/length without reading its audio) and a decode step (`DecodeV1Sound`, reads and decodes one entry's PCM on demand) — mirrors `sff`'s own parse/resolve separation
- Errors always name the offending `(group, sample)` entry and wrap the underlying cause with `%w`; malformed input never panics
- `DecodeV1Sound` only decodes WAVE format tag 1 (PCM), 8-bit unsigned or 16-bit signed — ADPCM is a permanent, documented scope cut (see `decisions/001`), backed by a corpus scan (496 real files, 54,306 sound entries, 0 ADPCM) and by Ikemen GO's own reference sound loader also only accepting PCM
- 8-bit PCM is re-centered around zero and scaled to the full 16-bit range on decode; `DecodedSound.PCM` is always signed 16-bit regardless of source depth
- Decoders are validated against real, unmodified community `.snd` files trimmed into `testdata/files/` via `testdata/gen` (mirrors `sff`'s own trimming-tool pattern), with expected values independently derived via Python's `wave` module rather than this package's own decoder
